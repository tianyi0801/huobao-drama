# 스토리보드 분할 가이드

## 핵심 정의: 스토리보드 구간

하나의 스토리보드 = 하나의 **스토리보드 구간**(segment) = 하나의 비디오 생성 작업.

- 구간은**준비—사건—반응**이라는 서사 박자를 담고 짧은 대화와 관련 동작을 함께 구성합니다. 고립된 동작마다 작업을 나누지 않습니다
- **정수4-12초**, 내용 먼저 길이 나중이며 고정 목표 초수를 두지 않습니다. 하드웨어로 컷 문법을 고정하지 않습니다
- **2-4개 서브 컷**은 기법 참고이지 수량 할당이 아닙니다. 롱테이크도 가능하지만 장면을 넘나들지 않습니다(`scene_id`는 구간 단위)
- 설정샷, 정반샷, 오버숄더, 동작·소품 삽입, 반응, 동기 있는 카메라·초점 이동을 사용할 수 있습니다. 각 인물의 위치와 시선을 명시하고 신원과 표정이 필요한 얼굴은 선명하게 하되 조연을 삭제하지 않습니다

## 분할 흐름(4단계)

1. `read_storyboard_context` 를 호출해 대본, 캐릭터, 장면, 소품, 기존 스토리보드 요약을 읽습니다
2. **박자 식별**: 중요한 전환에서 나누고 준비—사건—반응을 한 구간에 담습니다. 작업 범위를 넘을 때만 자연스러운 발화 교대나 동작 연결에서 나눕니다.
3. **컷과 길이 설계**: 관계 제시, 동작·디테일, 반응·결과를 먼저 설계하고 정보 변화, 시선과 화자 교대로 불균등한 길이를 배정합니다. 동시에 일어나는 발화·동작·반응을 중복 합산하거나 빈 시간으로 채우지 않습니다.
4. **배치 저장**: `save_storyboards`는최대2구간, 응답마다1회입니다. 이는 저장 배치 제한이지 서브 컷 수 제한이 아닙니다. 전체 재생성 첫 배치만`replace_existing: true`, 이후 추가하고 부분 편집에서는 삭제하지 않으며 전체 저장 뒤 완료합니다.

## 리듬과 컷 기법

- 전이는 새 공간을 빠르게 제시하고 정보가 명확해지면 진행합니다. 빈 장면이나 느린 푸시인을 반복하지 않습니다.
- 동작—디테일—반응, 정반샷과 오버숄더로 서사 왕복을 유지합니다. 원래 화자를 명시하면 대사가 듣는 사람의 반응 위로 이어질 수 있습니다.
- 중요한 발견과 감정 전환만 의도적으로 머문 뒤 리듬을 조입니다. 중요한 연기의 롱테이크를 허용하며 모든 컷을 같은 길이로 만들지 않습니다.
- 등분, 컷 수 할당, 일률적 최단 초수를 두지 않습니다. 읽을 수 있는 짧은 삽입과 반응은2초 미만도 가능하지만 대사는 자연스럽게 들어가야 합니다.
- 공간, 광원, 축선, 시선과 동작을 연결하되 카메라 위치와 구도가 같을 필요는 없습니다.

## 자연스러운 발화와 연기 길이

실제 언어, 감정과 필요한 쉼으로 시간을 추정합니다. 대사, 동작과 반응은 동시 진행할 수 있고 컷마다 고정2초를 추가하지 않습니다. 글자 수는 발화 속도 참고이지 구간 수 할당이 아닙니다.

원문을 유지하고 범위를 넘는 긴 문장만 자연스러운 의미 경계에서 나눕니다. 비정상적 빠른 발화나 동작마다 과도한 분할은 피합니다.

## 컷 요소

1. **컷 제목**: 구간의 핵심 내용을 3-5자로 요약(예: "악몽에서 깨어남")
2. **시간**: 구체적인 시각 + 조명 묘사
3. **장소**: 장면 전체 묘사 + 공간 배치 + 환경 디테일
4. **화면 크기**: 구간 내 주도 화면 크기; 여러 화면 크기의 구간은 조합으로 씁니다(예: "미디엄샷+클로즈업")
5. **앵글**: 정면/로우 앵글/하이 앵글/측면/후면
6. **카메라 무빙**: 고정/푸시인/풀백/팬/팔로우/트래킹(구간 내 서브 컷마다 다를 수 있음)
7. **화면 묘사** `description`: `【镜头1】…【镜头2】…` 형식으로 서브 컷별로 관객이 실제로 보고 듣는 내용을 서술합니다 — 화면(누가 + 구체적 동작 + 신체 디테일 + 표정)을 먼저 씁니다; 해당 서브 컷에 대사가 있으면 「캐릭터명이 말한다: 「대사」」 형식으로 해당 `【镜头N】` 안에 쓰고, 내레이션은 「내레이션: 내용」으로 씁니다
8. **화면 결과** `result`: 구간 끝의 즉각적인 결과 + 시각 디테일
9. **분위기** `atmosphere`: 조명 + 색조 + 소리 + 전체 분위기
10. **길이** `duration`: 정수4-12초. 내용 먼저 길이 나중이며 자연스러운 발화를 확보하고 고정 목표를 두지 않음
11. **장면 연결**: 기존 장면과 매칭되면 반드시 `scene_id` 를 채웁니다
12. **캐릭터 연결**: `character_ids` 를 채워 현재 구간에 관련된 0명 이상의 캐릭터를 바인딩합니다
13. **소품 연결**: `prop_ids` 를 채워 현재 구간에 등장하는 핵심 소품(0개 이상)을 바인딩합니다

## 장면 연결 규칙

- `read_storyboard_context` 가 반환한 `scenes` 를 우선 사용합니다
- `location + time` 으로 명확히 매칭되면 반드시 올바른 `scene_id` 를 채워 넣습니다
- 존재하지 않는 장면 ID를 임의로 만들지 마세요
- 대본 내용이 기존 장면에 명백히 해당하면 새 장면 묘사를 중복 생성하지 마세요

## 캐릭터 바인딩 규칙

- `character_ids` 는 반드시 `read_storyboard_context` 가 반환한 캐릭터 목록에서 선택해야 합니다
- 한 구간에 캐릭터가 없을 수도 있고, 여러 캐릭터를 바인딩할 수도 있습니다
- 구간에 명확히 출연하거나, 보이거나, 동작하거나, 말하는 캐릭터가 있으면 모두 바인딩해야 합니다
- 순수 환경 구간, 빈 장면, 사물 클로즈업은 빈 배열을 전달할 수 있습니다

## 소품 바인딩 규칙

- `prop_ids` 는 반드시 `read_storyboard_context` 가 반환한 소품 목록(`props`)에서 선택해야 합니다
- 소품이 캐릭터에 의해 사용되거나, 전달되거나, 클로즈업되거나, 화면에 뚜렷이 보이며 서사적으로 의미가 있을 때 반드시 해당 구간에 바인딩합니다
- 소품 클로즈업 구간(캐릭터 없음)도 소품을 바인딩해야 하며, `character_ids` 는 비워 둘 수 있습니다
- 줄거리와 무관한 배경 물건, 장면 비품은 바인딩하지 마세요; 소품이 등장하지 않는 구간은 빈 배열을 전달합니다
- 바인딩된 소품은 비디오 생성의 참조 이미지(화이트 배경 단품 이미지)로 사용되어, 소품의 외형이 구간을 넘어 일관되게 유지됩니다

## 품질 요구 사항

- 실제 모든`【镜头N】`에 순서대로 화면 크기, 위치, 시선, 동작과 원문 대사를 쓰고 각 컷이 새 정보를 전달하게 합니다. [Shot N]과 순서·전환점을 맞춥니다. 6절과 보이는 각 인물의 독립Subject를 사용하고 실제 이미지만@로 참조합니다.
- 원문 대사는 해당Shot에 한 번만 씁니다. overall_soundscape는 발화 허용 인물과 발화 구간, 환경·동작 소리만 적습니다. 각 인물은 자기 대사 구간만 말하고 그 외에는 발성하지 않습니다. 기존 내레이션을 유지하고 새 음성을 추가하지 않습니다. 정반샷 위로 원문 대사가 이어지는 것은 새 음성이 아니며 대사와 내레이션이 없으면 사람 목소리 없음을 명시합니다.
- non_diegetic_music는 요청이 없으면 음악과 노래 없음입니다. atmosphere만 보고 소리를 추가하지 않습니다
- 저장 도구schema의 필드만 사용합니다. 증분 `update_storyboard`에서 전체 화를 비우지 않습니다

# 스토리보드 분할 가이드

## 핵심 정의: 스토리보드 구간

하나의 스토리보드 = 하나의 **스토리보드 구간**(segment) = 하나의 비디오 생성 작업.

- 로컬 H3 기준: **정수4-12초, 목표5초, 최대12초**. 긴 대사는9-12초로 늘릴 수 있지만 억지로 채우지 않습니다
- 기본은**연속 한 컷과 주요 동작 하나**, 고정 카메라 또는 느린 단일 이동입니다. 서사상 필요한 경우만 최대 두 컷, 각2초 이상
- 장면을 넘나들지 않습니다(`scene_id`는 구간 단위). 줄거리와 원문 대사를 생략하지 않습니다
- 두 인물은 같은 초점면을 우선하며 각자의 외형, 위치, 얼굴 방향과 동작을 명시합니다. 조연의 얼굴도 선명해야 하며 얕은 심도로 흐리게 하지 않습니다

## 분할 흐름(4단계)

1. `read_storyboard_context` 를 호출해 대본, 캐릭터, 장면, 소품, 기존 스토리보드 요약을 읽습니다
2. **박자 식별**: 서사 경계에서 나눕니다. 인과 관계는 공간 기준과 동작을 이어 인접 구간으로 분리할 수 있으며 한 구간에 넣기보다 길이와 대사 용량을 우선합니다
3. **길이 추정**: 글자 수 ÷ 500 × 60은 초 단위 참고값일 뿐 구간 수나±20%를 강제하지 않습니다. 자연스러운 발화, 동작과 쉼을 합산하며 추정에 맞추려고 줄거리를 삭제하지 않습니다
4. **단순한 컷 설계**: 기본 한 컷이며 필요한 경우만 전환합니다. 전체 필드를 채운 뒤 `save_storyboards`로 최대2개씩, 응답마다 한 번 저장합니다. 전체 재생성의 첫 배치만 `replace_existing: true`, 이후 추가합니다. 명시적 부분 수정에서 기존 컷을 삭제하지 않고 모든 필요한 저장 후 종료합니다

## 리듬 계층별 길이

구간의 기능에 따라 길이를 정하며, 획일적으로 하지 마세요:

| 구간 유형 | 길이 | 설명 |
|---|---|---|
| 전이 구간 | 4-5초 | 이동, 빈 장면, 환경 설정, 전환 |
| 서사 구간 | 5-8초 | 줄거리 진행, 대화 |
| 긴 대사 또는 느린 동작 | 9-12초 | 자연스러운 발화와 쉼, 주요 동작을 우선하고 불필요한 전환을 피함 |

## 대사 용량

자연스러운 발화 시간과 약2초의 연기 여유를 확보합니다. 중국어4.5자/초는 참고이며 한국어의 일률적 기준으로 적용하지 않습니다.

담을 수 없는 대사는 반드시 다음 구간으로 나누며, 다 소화할 수 없는 대사를 한 구간에 욱여넣는 것은 허용되지 않습니다.

## 컷 요소

1. **컷 제목**: 구간의 핵심 내용을 3-5자로 요약(예: "악몽에서 깨어남")
2. **시간**: 구체적인 시각 + 조명 묘사
3. **장소**: 장면 전체 묘사 + 공간 배치 + 환경 디테일
4. **화면 크기**: 구간 내 주도 화면 크기; 여러 화면 크기의 구간은 조합으로 씁니다(예: "미디엄샷+클로즈업")
5. **앵글**: 정면/로우 앵글/하이 앵글/측면/후면
6. **카메라 무빙**: 고정/푸시인/풀백/팬/팔로우/트래킹(구간 내 서브 컷마다 다를 수 있음)
7. **화면 묘사** `description`: `【镜头1】…【镜头2】…` 형식으로 서브 컷별로 관객이 실제로 보고 듣는 내용을 서술합니다 — 화면(누가 + 구체적 동작 + 신체 디테일 + 표정)을 먼저 씁니다; 해당 서브 컷에 대사가 있으면 「캐릭터명이 말한다: 「대사」」 형식으로 해당 `【镜头N】` 안에 쓰고, 내레이션은 「내레이션: 내용」으로 씁니다
8. **화면 결과** `result`: 구간 끝의 즉각적인 결과 + 시각 디테일
9. **분위기** `atmosphere`: 조명 + 색조 + 소리 + 전체 분위기
10. **길이** `duration`: 정수4-12초, 목표5초, 최대12초이며 자연스러운 대사 용량을 확보함
11. **장면 연결**: 기존 장면과 매칭되면 반드시 `scene_id` 를 채웁니다
12. **캐릭터 연결**: `character_ids` 를 채워 현재 구간에 관련된 0명 이상의 캐릭터를 바인딩합니다
13. **소품 연결**: `prop_ids` 를 채워 현재 구간에 등장하는 핵심 소품(0개 이상)을 바인딩합니다

## 장면 연결 규칙

- `read_storyboard_context` 가 반환한 `scenes` 를 우선 사용합니다
- `location + time` 으로 명확히 매칭되면 반드시 올바른 `scene_id` 를 채워 넣습니다
- 존재하지 않는 장면 ID를 임의로 만들지 마세요
- 대본 내용이 기존 장면에 명백히 해당하면 새 장면 묘사를 중복 생성하지 마세요

## 캐릭터 바인딩 규칙

- `character_ids` 는 반드시 `read_storyboard_context` 가 반환한 캐릭터 목록에서 선택해야 합니다
- 한 구간에 캐릭터가 없을 수도 있고, 여러 캐릭터를 바인딩할 수도 있습니다
- 구간에 명확히 출연하거나, 보이거나, 동작하거나, 말하는 캐릭터가 있으면 모두 바인딩해야 합니다
- 순수 환경 구간, 빈 장면, 사물 클로즈업은 빈 배열을 전달할 수 있습니다

## 소품 바인딩 규칙

- `prop_ids` 는 반드시 `read_storyboard_context` 가 반환한 소품 목록(`props`)에서 선택해야 합니다
- 소품이 캐릭터에 의해 사용되거나, 전달되거나, 클로즈업되거나, 화면에 뚜렷이 보이며 서사적으로 의미가 있을 때 반드시 해당 구간에 바인딩합니다
- 소품 클로즈업 구간(캐릭터 없음)도 소품을 바인딩해야 하며, `character_ids` 는 비워 둘 수 있습니다
- 줄거리와 무관한 배경 물건, 장면 비품은 바인딩하지 마세요; 소품이 등장하지 않는 구간은 빈 배열을 전달합니다
- 바인딩된 소품은 비디오 생성의 참조 이미지(화이트 배경 단품 이미지)로 사용되어, 소품의 외형이 구간을 넘어 일관되게 유지됩니다

## 품질 요구 사항

- 기본 `【镜头1】`에 각 인물의 위치, 선명한 얼굴과 동작을 적습니다. `video_prompt`는 MiniMax 공식 Ref2VA 6절(subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music)을 영어로 작성하며 보이는 인물마다 독립 <Subject N>을 사용하고 실제 이미지가 있을 때만 @로 참조합니다
- 원문 대사는 해당 Shot에 <d>[Chinese] ...</d> 형태로 한 번만 쓰고 발화자에게 안정적인 (Sx)를 붙입니다. overall_soundscape는 1~4문장의 영어로 환경·동작 소리만 적으며 발화 허용 목록이나 대사 반복은 금지합니다
- retention_analysis는 공식 마커(fully_preserved / partially_preserved / attribute_transfer / weak_reference)만 사용합니다. non_diegetic_music는 요청이 없으면 N/A이며 atmosphere만 보고 소리를 추가하지 않습니다
- 저장 도구schema의 필드만 사용합니다. 증분 `update_storyboard`에서 전체 화를 비우지 않습니다

# 絵コンテ分解ガイド

## 中核の定義：絵コンテパラグラフ

1つの絵コンテ = 1つの **絵コンテパラグラフ**（segment）= 1つの動画生成タスク。

- 内容に応じた **4〜12整数秒**を使い、5秒目標も15秒への拡大も行わない。ローカル安定戦略であり、公式能力上限や品質保証ではない
- 原則1連続ショット・1主要行動、固定または簡潔な単一移動。物語上必要な切替のみ最大2ショット・各2秒以上とし、水増ししない
- 1段落1シーン（`scene_id` は段落単位）。隣接段へカメラ・人物・扉/窓/家具・主光の相対関係を引き継ぎ、空間の再導入を繰り返さない
- 1人か2人を優先し、同一焦点面で外観・位置・距離・顔の向き・独立動作を示す。物語の全人物と判別可能な顔を維持する
- 新規生成段落は主要話者1人を優先する。同じ人物の複数文は自然な発話尺があれば可、話者交代は新段落を優先する。公式のShot単一話者上限ではなく、既存台詞やショットの削除根拠にしない
- 通常速度で現在の行動に直接入る。導入、顔上げ・吸気、スローモーション、末尾静止で尺を埋めず、原文に根拠のある間や演技を維持する

## 分解フロー（4ステップ）

1. `read_storyboard_context` で脚本・人物・シーン・小道具・既存要約を読む。保存ツールの既存schemaのみ使用する
2. **因果とビート**：前提状態 → 現在の行動／誰が誰に原文を話すか → 即時結果と次段の継続を内部で整理する。転換点や話者交代で分け、位置と動作を引き継ぐ。計画をH3本文へ漏らしたり計画フィールドを新設したりしない
3. **尺の概算**：自然な発話・動作・必要な間・合理的な同時進行から求め、字数換算総尺や段数配額を置かない。12秒を超える内容は自然な意味/動作の境界で次段へ続け、台詞も物語も削らない
4. **設計と保存**：description の `【镜头N】` に可視行動と原文台詞を書き、video-prompt 権威スキルで動画欄を同時生成する。最大2段/バッチ、各応答1回 `save_storyboards`。全体再生成の初回のみ `replace_existing: true`、以後追記。差分編集で既存段を消さず、全保存成功後に終了する

## リズム階層別の尺

パラグラフの機能に応じて尺を決め、一律にしない：

| パラグラフの種類 | 尺 | 説明 |
|---|---|---|
| 短い反応 | 4秒 | 原文の反応と状態変化に直接入る |
| 通常対話 | 5〜8秒 | 自然な原文発話、同じ人物の複数文も可 |
| 連続動作 | 6〜10秒 | 通常速度の連続行動、準備動作を繰り返さない |
| 長い台詞 | 10〜12秒 | 原文の間を維持し、圧縮も12秒への水増しもしない |

区間は内容の目安で配額ではない。新規段落は4〜12整数秒を保ち、物語を省略しない。

## 自然な発話と動作の見積もり

中国語は**4.5〜5.5字/秒**、通常は**合計0.4〜0.8秒の余裕**で見積もる。感情の間は原文から考慮し、文や動作ごとに余裕を重複加算しない。他言語は自然な発話尺を用い、中国語速度を一律適用しない。

自然に同時進行できる動作と台詞は重複後の総尺を求め、順序が必要なら加算する。機械的な加算や無理な同時進行を避ける。12秒を超える内容は自然な意味/動作の境界で次段へ続け、全台詞・動作を維持し、汎用の間・スロー・末尾静止を足さない。

## カットの要素

1. **カットのタイトル**：パラグラフの中核内容を3〜5字で概括（例：「悪夢で目覚める」）
2. **時間**：具体的な時刻 ＋ 光線の描写
3. **場所**：シーンの完全な描写 ＋ 空間構成 ＋ 環境の細部
4. **ショットサイズ**：パラグラフ内で主導するショットサイズ。複数ショットサイズのパラグラフは組み合わせで書く（例：「ミディアム＋クローズアップ」）
5. **アングル**：目線／仰角／俯瞰／側面／背面
6. **カメラワーク**：固定／プッシュイン／プルバック／パン／フォロー／移動（パラグラフ内のサブカットごとに異なってよい）
7. **画面描写** `description`：`【镜头1】…【镜头2】…` ごとに行動を完全な文で書き、句点または改行で分けて `角色原名说：「原句」` の固定構文を使う。役名は業務資料の原名、台詞は完全原文とし、役名を翻訳せず行動文を話者名へ混ぜない。ナレーションは既存の内容のみ `旁白：「原句」` と記す
8. **即時結果と継続**：末尾の結果と次段の成立状態を `description` に書き、`result` や因果計画フィールドを追加しない
9. **雰囲気** `atmosphere`：光線 ＋ 色調 ＋ 環境の雰囲気。これだけで新配音や配楽を作らない
10. **尺** `duration`：4〜12整数秒。自然な発話と行動に十分な尺とし、目標尺への水増しをしない
11. **シーンの関連付け**：既存シーンにマッチできる場合は、必ず `scene_id` を記入する
12. **キャラクターの関連付け**：`character_ids` を記入し、現在のパラグラフに関わる0個以上のキャラクターを紐付ける
13. **小道具の関連付け**：`prop_ids` を記入し、現在のパラグラフに登場する重要な小道具（0個以上）を紐付ける

## シーン関連付けのルール

- `read_storyboard_context` が返す `scenes` を優先的に使用する
- `location + time` で明確にマッチできる場合は、必ず正しい `scene_id` を埋め戻す
- 存在しないシーンIDをでたらめに生成しない
- 脚本の内容が明らかに既存シーンに収まる場合、新しいシーン描写を重複して作らない

## キャラクター紐付けのルール

- `character_ids` は必ず `read_storyboard_context` が返すキャラクターリストから選ぶ
- 1つのパラグラフはキャラクターなしでもよいし、複数のキャラクターを紐付けてもよい
- パラグラフ内で明確に登場し、見え、動作し、または話すキャラクターはすべて紐付ける
- 純粋な環境のパラグラフ、空カット、物品のクローズアップは空の配列を渡してよい

## 小道具紐付けのルール

- `prop_ids` は必ず `read_storyboard_context` が返す小道具リスト（`props`）から選ぶ
- 小道具がキャラクターに使われる、受け渡される、クローズアップされる、または画面内で明確に見えて物語上の意味がある場合は、必ずそのパラグラフに紐付ける
- 小道具のクローズアップのパラグラフ（キャラクターなし）も小道具を紐付ける。`character_ids` は空でよい
- 物語と無関係な背景物品、シーンの調度品は紐付けない。小道具が登場しないパラグラフは空の配列を渡す
- 紐付けられた小道具は動画生成の参照画像（白背景の単品画像）として使われ、パラグラフをまたいで小道具の外観の一貫性を保証する

## 品質要件

- description の `【镜头N】` に前提状態、各人物の行動／誰に原文を話すか、即時結果と継続を書く。ナレーションは原文のみ。マーカーを動画ショットの唯一の根拠とし、話者戦略で増減しない
- 公式六節の英語説明本文は video-prompt 権威スキルに従い、台詞・歌詞・可視文字は原言語を保つ。画像番号、Subject/Sx、音、動画スタイルの詳細はここで重複定義しない
- 既存書き直しでは duration、ショット数、全動作・台詞を維持する。複数話者を各文の主体IDに紐付け、新安定戦略で削らない
- 保存前に話者・順序・完全原文・回数、行動因果・実尺・空間継続を照合する。既存ツールschemaのみ使い、result、image_prompt、bgm_prompt、sound_effect 等を新設しない
- 差分 `update_storyboard` で話全体を消さない
